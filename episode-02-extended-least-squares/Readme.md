# Episode 02: Unknown Systematic Errors & Extended Least Squares (ELS)

This repository contains the full production materials, bilingual LaTeX speaker scripts (German & English), compiled PDFs, and the underlying peer-reviewed research paper for **Episode 02: Unknown Systematic Errors**.

It demonstrates how to address model gaps and unknown systematic uncertainties using a simultaneous parameter and error modeling approach—specifically applied to dislocation density degradation during the tempering of chromium stainless steel (Böhler N404).
